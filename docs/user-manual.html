先理清几个概念

先分清角色、参考与产物的关系。手册中的示意图解释规则；店长立绘为现有图库实图，界面截图使用隔离演示数据。

精灵一个角色。它下面挂着一批动作，还带一份全角色统一的「工艺预设」。
动作角色的一个动作，如走路、待机。每个动作有自己的素材视频、帧、导出产物。工作台里打开的就是它。
素材版本同一个动作可以生成多次视频，每次是一个版本，可切换、可对比，标为「当前使用」的那个参与后续工序。
参考视频模板一段示范动作的视频，决定生成时的动作节奏。抽帧规则也存在它身上。动作要「绑定」到模板才能用这些。
参考首帧集一整套已完成角色的动作首帧。生成新角色首帧时，用它提供姿势参考。
角色模板绑定固定角色主分组、唯一参考首帧集，以及允许跨组复用的参考视频。避免同名动作误用别组素材。
「模板」在界面上有两处：动作模板（参考视频）和 Spine 导出模板，两者无关。

一个角色怎么从头做到尾

  1. 在精灵库新建角色。可以选一个已有角色当模板，继承它的动作骨架，省去逐个建动作。
  2. 进入角色动作看板 →「模板绑定」：确认角色主分组、固定参考首帧集与共享参考动作。
  3. 到「首帧图库」上传角色立绘，并标记「正面立绘」（有背面动作的话也标背面）。
  4. 为每个动作准备首帧：可以用 AI 按参考首帧集生成，也可以直接上传。
  5. 视频生成：选参考视频模板 + 提示词，生成素材视频。
  6. 抽帧：从视频抽出帧序列。同模板的动作可以沿用已存的抽帧规则。
  7. 背景抠图：把绿幕/背景去掉，得到带透明通道的帧。
  8. 导出：序列帧 / 精灵图 / GIF，或整角色导出 Spine 资源。

首帧到导出可以用「一键流水线」串起来自动跑，执行前先看计划预览。

项目、精灵类型与多级分类

精灵库顶部选择项目，左侧浏览分类目录和精灵类型，右侧展示当前范围内的角色。目录负责整理，类型负责关联默认参考配置，标签用于交叉筛选。

  1. 点击「管理项目 / 分类 / 类型」，先新建项目，再新建所需目录。目录可嵌套，例如「人物 / 工作人员」。
  2. 切换「精灵类型」，在项目和目录下建立「店长」等类型；可配置新角色默认参考分组、首帧集和共享动作。
  3. 回精灵库选择项目，再点击类型，使用「新建店长」。角色带入当前项目与类型；需要完整动作骨架时，仍选择同项目的样板角色。
  4. 旧角色默认保留在「待归类（旧数据）」；勾选角色，点击「归类所选」，选择项目与类型，先预览再确认。参考分组冲突会阻止归类，需要明确调整角色绑定或选择其他类型。
归类只修改角色归属，不套用类型默认绑定，不改原标签、素材路径、动作、立绘标记或工艺。类型默认设置的更新只用于后续新建，不会自动升级现有角色。

点击上层目录可查看其全部后代类型的角色，三角按钮展开或折叠。改名、调整父目录不影响稳定 ID 与素材路径；目录不能形成循环、不能跨项目移动；仍被引用的条目不能删除。

批量导入使用当前项目与类型作为初始目标。同名角色仅在相同项目、相同类型内复用，出现多条同名候选时会跳过并报错。原项目包按标签筛选的功能保留；跨服务器导入若找不到原分类 ID，角色仍可从待归类中找到并重新明确归类。

多角色：绑定模板与参考集

入口：精灵库 → 打开角色 → 动作看板「模板绑定」。新建时从模板角色继承绑定，保存前仍应核对；默认不复制模板角色的成品首帧。

  1. 填写「角色主分组」，例如「店长」。分组应与准备使用的参考首帧集一致。
  2. 在「固定参考首帧集」选择本组的一套参考。已有店长参考集时直接选用，不必重复归档。
  3. 没有参考集时，在下方选择已完成的样板角色，点「将该角色首帧归档到本组」。这只复制现有首帧；归档成功后还要点「保存绑定」。
  4. 已有动作若使用其他分组的参考视频，在「跨组共享参考动作」逐项勾选需要的条目。未勾选的外组参考不能使用。
  5. 检查「本角色动作与参考绑定」，点「保存绑定」。再进入首帧或流水线确认计划。

用店长1带出新店长的例子

店长1的 11 张首帧已归档为「店长参考集（店长1）」。店长1和店长2均绑定该集；既有旅馆 NPC 的正面待机、正面走路、背面待机三个参考视频已明确授权共享。其他外组参考仍需单独勾选。此配置记录截至 2026-10-19，之后以界面当前值为准。

共享参考视频不会把首帧集也切到外组。固定参考集缺 key、已删除或被改了分组时会阻塞；应补齐本组参考或明确修改绑定，不会自动从其他集补图。

更改绑定不会替换现有视频、首帧或导出。MCP 未消费的旧生成审批会因绑定变化失效，需要重新规划和审批。

把素材批量导进来

三处支持批量导入：参考视频库（模板视频）、首帧参考集（一整套首帧图）、批量建档（角色 × 动作）。

都是点「选择文件夹」，选你自己电脑上的文件夹，连同子目录一起传到服务器，传完自动接着导入。浏览器会先过滤一遍，只传图片或视频，文件夹里混着的 PSD、源工程不会传上去。

文件夹怎么放

  • 参考视频库：文件夹里直接放视频，文件名形如「01_walk (走路).mp4」，key、变体、推荐时长都从文件名解析。
  • 首帧参考集：文件夹里直接放图片，文件名主干就是动作 key；参考集名称默认用文件夹名。
  • 批量建档：选的是根目录——里面每个子文件夹是一个角色，子文件夹里的图片名就是动作 key。只有一个角色也照样选根目录。
浏览器选不了文件夹时，点旁边的「zip」：对着文件夹本身右键压缩成 zip 再传，效果一样。

「或填服务器上的目录」那个输入框是给管理员用的：素材已经在服务器上（比如几十 G 直接拷了过去）时，填路径就不用再从浏览器传一遍。

首帧

首帧决定角色长相与起始姿势，后面生成的视频都锚定它。可以上传，也可以 AI 生成。

AI 生成需要两张参考图：角色立绘（决定长相）和参考首帧集里同一动作的图（决定姿势）。所以立绘必须先标记，参考集里也得有这个动作。

先标记当前角色自己的正面、背面立绘

  1. 从当前角色动作看板打开「首帧图库」，查看已有图片；有可用立绘就直接使用，没有再上传。
  2. 选择完整、清晰且外观一致的正面图，标记为「正面立绘」；背面图标记为「背面立绘」。每个方向只保留一张标记，改标新图会清除旧图的同方向标记。
  3. 回到首帧生成页，核对当前角色固定参考集。批量前检查每行可用状态；流水线先看计划预览，确认后再启动。

方向按动作 key 判断：包含 back 的 key 使用背面，其余使用正面。没有背面标记时程序可回用正面，但背面动作建议补齐背面图，保证外观参考准确。

参考集是按 key 匹配的

每个动作有一个 key：绑了参考视频模板就用模板的 key，没绑就用动作名。生成时拿这个 key 去参考集里找同名的图。

批量生成弹窗里如果某行显示「参考集缺「01_idle_front」」，就是这个 key 在所选参考集里找不到。若后面还跟着「有相近的「01_idle」」，多半是命名差一截，不是真缺图。

AI 生成首帧按张计费。批量前先看清楚勾了几张，弹窗按钮上有数量。

素材速览：一次看完全部首帧或视频

动作看板上的「速览首帧」「速览视频」，把全角色的素材铺成一张网格，肉眼一次扫完，不用逐个打开工作台。

  • 视频静音循环自动播——动画类素材要看动起来才看得出问题。
  • 只在滚动到可视范围时才加载，二十来段视频不会一起压上来。
  • 点任意一项放大，放大后用 ← → 连续翻看，不必退出再点下一个。
  • 勾「只看缺的」筛出还没有素材的动作。

就地改提示词再重生成

每格下面是该动作会用到的提示词，由服务端按生成时的同一套规则解析，看到的就是重生成时真正会用的那条。可以直接改，改过的边框变橙并标「已改」，点「重新生成」才会生效——光改不点是不会跑的，不会误触发计费。

顶部的「改动记为设定」默认开着：改过的提示词会记为该动作的设定，下次打开与批量生成都沿用。只想试这一次就取消勾选。

「打开」按钮跳到该动作的工作台，需要调参数（时长、分辨率、换模板）时走那边。

视频一栏看的是各动作「当前使用」的那个版本。同一动作有多版时会标出版本数，要比对具体哪一版请进该动作的视频生成页。

视频生成

首帧 + 参考视频 + 提示词 → 生成一段动作视频。每生成一次是一个素材版本。

模板下拉与「绑定到此动作」的区别

已配置角色模板绑定时，下拉只显示主分组与逐项授权的共享参考。要新增外组参考，先回看板的「模板绑定」勾选对应条目。

下拉选模板只决定本次生成用哪个参考视频，不会记住。
绑定到此动作把模板写进动作档案。绑定后才能沿用/保存抽帧规则，批量生成也会默认用它。

所以选了模板生成完，如果没点「绑定到此动作」，抽帧页是看不到规则相关按钮的。看板上那一列会显示「未绑定」。

素材版本

同一动作可以生成多版，在版本墙里预览对比，把满意的标为「当前使用」，后续抽帧就用它。删除付费生成的版本会有提示。

生成按次计费，且有并发上限。超出上限的任务会显示「排队中」，这时点取消是立刻生效的，不会白花钱。

抽帧

从当前素材视频按时间区间和帧率抽出帧序列。重抽会清空已有的帧。

抽帧规则

同一个模板生成出来的视频，动作节奏是一致的，所以抽帧参数可以复用。规则存在模板上，内容是：起止时间、帧率，以及删帧之后保留了哪几帧。

  • 「沿用模板规则」：把模板上存的参数填进来，抽完还会自动删掉保留集之外的帧。
  • 「保存为模板规则」：把这次的参数和当前保留的帧存回模板，之后同模板的动作都能沿用。

两个按钮都要求动作已绑定模板。没绑定时这里会写明原因并给「去绑定」的入口。

规则只能存到本动作相关的模板上（动作绑定的，或当前视频版本所用的）。写到别的模板会被接口挡下并说明原因。

动作分析（可选）

用姿势、轮廓、图像特征或区域相似度来比较帧，帮助精简序列。

  • 去相似帧：相邻帧太像的删掉，减少无效帧。
  • 找循环帧：找出和首帧最接近的那一帧，用来裁出一个能循环播放的片段。

姿势模式需要本地安装 RTMPose 模型，没装时用轮廓或图像模式。

背景抠图

把背景去掉，得到带透明通道的帧。抠图结果写入「处理后」图层，帧管理里有绿色徽标。

  • AI 抠图：需要本地装模型。精简安装包不含模型，要按说明另行下载。
  • 颜色抠图：绿幕/蓝幕用，不需要模型。

抠图参数与精灵预设

同一个角色的所有动作应该用同一套参数，否则边缘会不一致。参数存成「精灵预设」后全角色统一，偏离时页面上会明确标出。

边缘有白边时别把 Alpha 阈值填 1~50 的小值，那会把淡白边缘提升为完全不透明，白边反而更重。用 0 或 128 以上。

图像处理：描边与缩放

这一页有两种用法，区别很大，先看清楚。

页面上的按钮就地改帧。直接覆盖处理图层，重复执行会叠加，只能用历史回退撤销。
存为导出预设不动帧文件。导出时才应用，顺序固定为先缩放后描边。

日常用导出预设。需要把效果烧进帧里再做别的加工时，才用就地处理。

为什么顺序是先缩放后描边

先描边再缩小，描边会跟着一起变细：3px 缩到四分之一就只剩不到 1px。先把尺寸定稿再描边，填几 px 成品里就是几 px。

Spine 导出的尺寸由画布决定，不吃这里的缩放预设，两者不会叠乘。

导出

支持序列帧、精灵图（PNG + JSON）、GIF、WebP、Godot SpriteFrames。

  • 导出时会按精灵预设应用缩放与描边，作用在副本上，帧文件保持原分辨率。
  • 循环过渡：导出时在首尾之间插入过渡帧，让循环播放更顺，同样不改原帧。
  • PNG 压缩（pngquant）可选，能明显减小体积。

文件名默认就是动作名——同一个角色下每个动作各自一个名字，导出到一起不会互相盖。单独帧就是 动作_0001.png，导出目录同名。

名字里可以用占位符：{action} 动作名、{anim} 该动作的 Spine 动画名（wait1/walk1…）、{sprite} 角色名，可以拼，如 {sprite}_{anim}。存 {anim} 的话，以后 Spine 动画名改了文件名跟着改。右边实时显示这次实际会用的名字。

给单个动作取导出名

填好名字点「存为该动作的导出名」，就挂在这一个动作上：动作名本身不动，以后这个动作导出（包括一键流水线）都用这个名字。别的动作不受影响，点「清除」落回动作名。

这和 Spine 动画名是同一个思路：我们的动作名是固定的，对外叫什么会变，所以做成一层可随时改的关联，改名不影响已有数据。

「保存为精灵导出预设」存的是导出格式与参数（该角色所有动作共用），不含文件名——文件名一律按动作走，自动流水线导出的也是动作名或该动作存的导出名。

导出记录可以重新下载。多个文件打成 zip，解开自带「角色/动作」两层目录——几个角色的产物解到同一个地方也不会混在一起；只有一个文件时直接下载，文件名前面带角色名。

产物尚未完成时，下载会被阻止。等待导出任务成功后再下载；失败或半成品目录不能作为成品交付。

Spine 资源导出

把整个角色的序列帧打成 Spine 能直接打开的骨架数据与图集。入口在动作看板右上角。

{骨架名}.json     骨架数据（Spine 里 Import Data 选它）
{骨架名}.atlas    图集索引
{骨架名}.png      图集贴图
images/           序列帧

.spine 是私有格式，官方没有接口能生成。需要工程文件时在 Spine 里 Import Data 选上面的 JSON，再另存为 .spine。

动画名从哪来

默认取参考视频库里每条模板的「Spine 动画名」字段；没填的按变体名推断（走路→walk1、工作→sit_work1），也可以在模板库里一键套用建议值。

导出弹窗的动作表里每行都能直接改名，只改这一次导出；勾上「记到动作」就记到动作上，之后手动导出和一键流水线的自动导出都用这个名字。改回推断值时会自动取消记住，重新由模板说了算。

选了导出模板时，改名输入框会列出模板里已有的动画名——挑一个就把这个动作接到该动画上；填模板里没有的名字会标黄，表示会当成新动画导出。

把动作关联到模板动画

两边的命名往往是两套规矩：这边叫 03_walk_checkin_front，模板里叫 checkin_walk1。点「自动匹配」按名字对一遍——去掉序号前缀、正面认作编号 1、背面认作 2、词序不同也认，对不上的留空不乱配。填好的可以再手改。

勾「存为模板关联」导出后，这套「动作名 → 动画名」就存在该 Spine 模板上。换个角色只要动作名一样，打开就已经对好了，不用再对一遍。

行尾的小标记说明名字是哪来的：记＝记在动作上（只这个角色）、模＝来自模板的动作关联、?＝模板里有个像是对应它的动画，点自动匹配即可填上。

两个动作重名会互相覆盖，导出前后端都会拦下来，并指出是哪两个动作撞了。

导出模板：照抄既有工程的约定

一套 Spine 工程里有不少约定只存在于文件本身：骨架版本、帧命名格式、附件的渲染尺寸、图集压缩比、每个动画的插槽名与对齐偏移。导入一次，之后选用该模板即可照抄。

两种导入方式：服务跑在本机就填参考工程的目录（或 .json / .skel）路径；跑在别的机器上就点「上传 zip」——把工程整个打包传上去即可，只会取里面的 .json / .skel / .atlas，图片不上传也不影响解析，单个 .json / .skel 也能直接传。

当前只支持纯逐帧贴图动画。参考工程里若有网格或裁剪附件会直接报错拒绝；多套皮肤能解析但只产出 default 一套。

产物在哪下载

导出弹窗底部有「已导出的产物」列表，手动导的和流水线自动导的都在这里，随时可以再下载或删除。

一键流水线

把 首帧 → 视频生成 → 抽帧 → 抠图 → 导出 串起来，对多个动作批量执行。每个动作一条独立任务。

  • 执行前有计划预览：每个动作每一步是「将执行」「已完成跳过」还是「阻塞」，阻塞会写明原因。
  • 已有产物的步骤自动跳过，所以再点一次就是从失败或未完成处续跑。
  • 首帧生成后可以暂停等人工确认，过目满意再继续后面的工序。

缩放与描边不是独立步骤

它们在「导出」这一步按精灵预设应用。计划表里会列出导出时会做哪些处理。

完成后导出 Spine

勾上以后，这批动作全部跑完会自动把整个角色打成 Spine 资源。由最后完成的那个动作触发，同时跑完也只导一次。中途有失败的就不导，补跑完成后会自动接上。

并发、排队与取消

全局任务管理与停止全部

顶栏「全局任务」可查看服务器任务，刷新页面或换浏览器后仍可查询。支持按状态、任务类型和角色/动作名称搜索，并打开对应动作。历史记录若未保存动作归属会明确标注，不猜测归属。右下角本页任务栏也可进入全局管理。

「停止全部任务」先暂停新任务提交，再取消全部排队和运行任务；已完成的素材、导出和历史记录保留。运行任务显示「正在停止」，在可中断点退出；同步生图或当前推理调用可能无法立即中断，远端视频只能尝试取消，不保证退费。

停止全部后，新任务保持暂停，重启服务也不会自动开放。确认整理好素材后，手动点击「允许新任务」；已取消或中断的任务不会自动重新提交。「暂停新任务」只阻止新增提交，不停止已经在执行或排队的任务。

调用外部接口的工序（视频生成、AI 生首帧）有并发上限，超出的排队。上限可在设置里调。

  • 排队中的任务状态显示「排队中」，不会谎称已在生成。
  • 排队期间点取消立刻生效，不会真的发出请求，也就不会计费。
  • 排队的任务不占用线程，不会把其他任务堵住。

同步接口（AI 生首帧）拿不到真实进度，进度条按已等待秒数推进，越等越慢且不会到顶——那是心跳，不是预估剩余时间。

抠图与导出为什么也会排队

本地抠图和导出共用内存预算，同时受各自并发上限约束。即使没有同类任务，也可能正在等待另一类任务释放内存。先看任务中的等待原因，避免连续重复提交。

任务记录会持久保存。服务重启不代表任务自动成功或继续执行；检查恢复后的实际状态与错误，再决定续跑。已完成的免费工序可跳过，强制重做仍会检查输入。

MCP：查询、加工与受控生成

MCP 供 AI 助手调用，权限与网页管理员入口分开。角色模板绑定、分组和固定首帧集的检查同样生效。

read查询角色、素材、任务、平台状态及自己的生成用量；不能提交加工或付费生成。
operate免费加工：先 plan_processing 查看抽帧、抠图、导出计划，再 submit_processing_batch 提交。
generate付费生成：先 plan_generation，管理员审核并配置额度与一次性审批后，再 submit_generation_batch。拥有此权限仍不能跳过审批。
  1. 先试产：trial 一次一个动作，检查计划中的角色、参考素材、提示词、模型、调用次数与视频秒数。
  2. 管理员审核完整计划并审批；试产成功后人工确认外观与动作，再由管理员定型。
  3. 量产 production 只接受同一已定型工艺。素材、提示词、绑定或参数变动后，重新规划和审批。
  4. 提交遇到网络超时时，使用同一个 request_id 重试，避免当作新任务重复提交。
  5. 用 get_generation_batch 查看批次，用 get_generation_costs 查看额度预留与尝试记录。实际金额以供应商账单为准。
未配置生成额度时默认为零；原只读密钥不能加工或付费。接口超时不代表未计费，已尝试调用不会自动退回额度，也不会自动重发同步生图。取消只阻止后续调用并尝试取消远端视频，不保证已经发出的调用退款。

哪些操作会改动原帧

分清这个，能避免大部分「改坏了退不回去」的情况。

会改帧抽帧、抠图、图像处理页上的按钮（描边/缩放/裁剪/边缘优化/增强）、魔棒编辑。可用历史回退撤销。
不改帧导出时的缩放与描边、循环过渡、Spine 导出。只作用于导出的副本。
历史回退按步骤恢复帧数据，但不会撤销已保存的模板规则、精灵预设这类配置。

常见问题

抽帧页看不到「保存为模板规则」

该动作没绑定参考视频模板。页面上会写明并给「去绑定」，或到「视频生成」页选好模板点「绑定到此动作」。如果显示的是「模板信息没取到」，那是请求失败，点重试即可。

批量生成首帧里某些动作是灰的

先看行尾原因：可能缺立绘标记、未配置模板绑定，或固定参考集缺少动作 key。到当前角色图库标记立绘，或在「模板绑定」补齐本组参考集；若需换集，先明确修改角色绑定。也可以给这个动作单独上传首帧。

提示「角色尚未配置模板绑定」或「参考动作不属于角色模板分组」

回角色动作看板 →「模板绑定」，保存主分组和固定参考集。确需复用外组参考视频时逐项勾选共享授权；不要只改动作名，也不要反复提交生成。

导出长时间排队或提示内存预算不足

查看是否有抠图或其他导出占用资源。单个任务估算超过总预算时等待也无法解决，应降低输出尺寸、调整图集列数或拆分导出；管理员再结合实际内存评估预算与并发。

抠图边缘有一圈白边

换边缘更锐的模型，并设 Alpha 阈值 128、腐蚀 1、羽化 0。切忌把阈值填 1~50。

描边在成品里变细了

用的是页面上的就地描边，之后又缩小了。改用「存为导出预设」，导出时会先缩放后描边，宽度就准了。

生图报「取回失败：连不上 …tos-….volces.com」

图已经生成了（这次调用已计费），卡在从对象存储下载那一跳。结果图和接口不是同一个域名，机器只放行了接口域名、或走代理没配全就会这样。服务会自动重试 3 次，仍不通就检查这台机器到该域名的网络；长期不通可在 backend/.env 里设 SPRITE_ARK_IMAGE_B64=1，让接口直接把图回过来，省掉这一跳。

任务显示「等待同会话的其他任务完成」

同一个动作的后台任务是串行执行的，避免并发改写同一批帧。等前一个跑完即可。
