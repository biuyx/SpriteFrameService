# 多角色模板的明确绑定

角色看板新增「模板绑定」。每个角色保存独立的 `template_binding`：

```json
{
  "group": "店长",
  "first_frame_set_id": "fs_...",
  "shared_template_ids": ["tp_..."]
}
```

`group` 是角色模板主分组；`first_frame_set_id` 是唯一允许的姿势参考首帧集，必须属于该分组。
动作仍通过原有 `template_id` 明确关联参考视频。主分组内的视频可关联，其他分组的视频必须逐项列入 `shared_template_ids`。
例如店长可复用旅馆 NPC 的待机/走路参考，但须明确授权这些参考视频 ID；姿势参考仍使用店长角色绑定的首帧集，不从 NPC 集里补取。

## 配置流程

1. 打开角色看板的「模板绑定」，选择主分组。
2. 选择同组的固定参考首帧集；如果尚不存在，选择样板角色，点击「将该角色首帧归档到本组」。归档只复制现有首帧，不发起生成，不修改源角色。
3. 对已有跨组动作逐项勾选共享授权；否则保存会明确提示冲突动作。
4. 保存角色绑定。各动作的参考视频仍在工作台的视频生成页通过「绑定到动作」明确选择；下拉只提供本组及已授权共享的视频。
5. 新角色从模板角色创建时继承绑定与动作配置，默认不复制旧角色的首帧和立绘；上传新角色自身立绘后生成新首帧。

首帧选择、角色立绘和生成产物分别属于不同概念：共享参考集只提供姿势，新角色立绘仍从该角色自身图库读取，生成结果写入该角色动作目录。
参考首帧集删除、分组变动、缺少动作 key 或显式覆盖了角色固定绑定时，操作会阻塞，不会换用别组或别集。

## 旧数据与付费流程

已有视频、首帧、抽帧和导出不会被迁移、替换或清空。已完成工序仍可跳过。
旧角色未配置绑定时，自动生成（包括 MCP）会提示先配置，不再扫描全局首帧库；手动指定参考集仍可使用，但动作模板有分组时要求分组匹配。
未分组的旧动作只接受用户明确指定的参考集，不会自动选择。
没有首帧集时可以先保存角色主分组，视频与已有素材处理不受影响，首帧生成会明确阻塞。

批量目录导入遇到同 key 多模板，不再取第一个，而是建档后提示需要明确选择；分组导入不接受该分组以外的显式模板 ID。
本次不根据角色名称、已有素材或最近导入时间自动猜测并改绑生产数据；实际样板角色由用户指定或在界面选择。

M3 生成计划记录角色绑定，绑定变化会使未消费的旧审批失效，需要重新规划和审批；工艺定型摘要包含角色模板分组。
网页、批量首帧、流水线和 MCP 共用后端校验，付费调用前复核参考权限；免费抽帧排队后也重新校验原计划参考是否仍被允许。
AI 密钥、generate 权限、额度和原有资源预算没有改变。模板绑定配置通过已有管理员角色 API 保存，不新增 MCP 写工具。
